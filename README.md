# Auvane

ABD pazarı için doğum haritası ve kendini keşfetme uygulaması (Expo + Supabase). Ayrıntılar için önce `CLAUDE.md`, sonra `docs/LINKS.md`.

| Klasör | İçerik |
|---|---|
| `ref/` | Referans hesap kodu (`calc.mjs`, `hd.mjs`) ve testleri. `cd ref && npm install && npm test` |
| `prototype/` | Ekran prototipinin kaynak dosyaları (tasarım, kod değil) |
| `docs/` | Şartname ve devir notu bağlantıları |

Depo özeldir ve içinde kişisel test verisi vardır; public yapılmaz.
